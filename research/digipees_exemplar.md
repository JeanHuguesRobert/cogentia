# Digipees Exemplar

`Digipees` is used as a compact real-world experiment joining three Cogentia/JHN objectives.

## 1. Free JHN trademark-assistance service

Build a lightweight service to help a user prepare an INPI trademark filing or decide whether deeper professional research is warranted.

Target capabilities:

```text
proposed sign
→ intended uses
→ plausible Nice classes
→ public INPI data / APIs
→ identical candidates
→ deterministic orthographic / phonetic similarity
→ relevant candidate packet
→ judgment boundary for semantic / contextual assessment
→ Continuation
→ user's AI agent or human judge
→ StepResult
→ resumed report
```

The service is an assistant, not a legal opinion. It must preserve sources, uncertainty, and the distinction between screening and legal availability.

It may also explain adjacent evidence options such as e-Soleau or other timestamping methods without confusing proof of date with trademark rights.

## 2. Institutional Intent–Reality Gap case

Use the same experiment to compare:

```text
declared mission / public-service intent
vs
actual free service available
vs
paid enhanced services
vs
capability demonstrated by the JHN exemplar
```

Record facts first. Interpretations such as inertia, risk aversion, regulatory or commercial rent, institutional decoupling, double discourse, or negligence remain hypotheses until supported.

The empirical question is not "is the institution bad?" but:

> **What explains the measurable gap between attainable capability and delivered capability?**

## 3. Portable Continuation demonstration

The first UX deliberately requires no A2A or MCP integration.

```text
JHN service
→ [Copy continuation]
→ user's ChatGPT / Claude / Gemini / local agent / human
→ [Copy StepResult]
→ [Paste result]
→ JHN resumes
```

This demonstrates that the logical cooperation protocol precedes transport automation.

Later transports may include MCP, A2A, HTTP, or Cognitive Packet routing without changing the core protocol:

```text
Continuation → Judgment → StepResult → Resume
```

## Success criteria

The experiment succeeds if it demonstrates all three of the following:

1. **useful capability** — a user receives materially more useful first-line trademark screening at negligible or very low service cost;
2. **measurable comparison** — the service produces enough data to compare user effort, capability, cost, and residual limitations against existing public options;
3. **provider-neutral cooperation** — the judgment step can be completed by the user's chosen agent using at least copy/paste transport.

The experiment should publish its failures and residual constraints as readily as its successes.
